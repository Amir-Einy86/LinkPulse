# لینک‌پالس — فرانت‌اند

فقط HTML، CSS و JavaScript (ES6)؛ بدون React، Vite و Tailwind. این پوشه با API بک‌اند حرف می‌زند و خودش داده‌ی نمونه ندارد.

## چطور اجرا کنم؟
ساده‌ترین راه: بک‌اند را اجرا کن (راهنما در `../README.md`)؛ خودش این پوشه را سرو می‌کند و روی `http://localhost:5000` همه‌چیز کار می‌کند.

اگر فرانت را جدا هاست می‌کنی، در `js/config.js` مقدار `apiBase` را آدرس بک‌اند بگذار و آن آدرس را در `CORS_ORIGINS` بک‌اند اضافه کن.

## صفحه‌ها
| فایل | صفحه |
|---|---|
| `index.html` | لندینگ (کوتاه‌کننده‌ی سریع) |
| `register.html` / `login.html` | ثبت‌نام / ورود |
| `dashboard.html` | داشبورد |
| `my-links.html` | لینک‌های من (جستجو، فیلتر، حذف گروهی، CSV) |
| `link-details.html` | آمار یک لینک (`?id=`) |
| `profile.html` / `settings.html` | پروفایل / تنظیمات |
| `404.html` | پیدا نشد / منقضی‌شده (سرور برای لینک‌های ناموجود نشانش می‌دهد) |

## ساختار
```
css/        base (رنگ‌ها)، components، app (پنل)، site (صفحه‌های عمومی)
js/         utils، config، api (fetch + نشست)، data (لایه‌ی API)، ui، charts، layout، link-modal
js/pages/   یک فایل برای هر صفحه
```

## محدودیت‌های شناخته‌شده
- توکن ورود در localStorage ذخیره می‌شود (اگر XSS رخ بدهد در خطر است؛ CSP سرور این را کم می‌کند).
- بازیابی رمز عبور ندارد.
- QR کد ندارد. لوگو موقت است.
